# ВК-бот книги рецептов

Бот добавляет новые рецепты на сайт, меняет и удаляет старые. Пишешь ему в сообщения сообщества ВК, через минуту изменения уже на сайте.

Как это устроено:

1. Сообщение попадает в маленькую программу на Cloudflare (`worker/worker.js`). Она отвечает «Получила!» и передаёт сообщение на GitHub.
2. На GitHub запускается `bot/process.py`. Он разбирает текст, сжимает фото, правит `data/recipes.json`, пересобирает `recipes.js` и публикует сайт.
3. Бот отвечает в ВК, что именно сделал, и даёт ссылку на рецепт.

Всё бесплатно.

## Как писать боту

**Новый рецепт.** Одним сообщением: фото блюда **файлом** (скрепка → Файл, PNG с вырезанным фоном) и текст:

```
Тыквенный крем-суп
Нежный суп из запечённой тыквы со сливками.
Раздел: Первое
КБЖУ: 62/1,4/3,2/7
Ингредиенты: тыква 1шт, сливки 20% 200мл, лук 1шт, соль по вкусу
Приготовление: 1. Почистите тыкву (понадобится тыква) 2. Обжарьте лук (понадобится лук) 3. ...
```

- Первая строка - название, под ней описание.
- КБЖУ - на 100 г готового блюда: ккал/белки/жиры/углеводы.
- Граммовки бот приведёт к одному виду: 10г, 1,5кг, 310мл, 1л, 2 ст.л., 1 ч.л., 3шт, 0,5уп.
- В скобках `(понадобится ...)` - что показать в подсказке «что понадобится» к шагу. Количество бот возьмёт из списка ингредиентов.
- Разделы: Первое, Второе, Выпечка несладкая, Десерты, Салаты, Напитки, Закуски, Заготовки.

Если фото отправить обычной картинкой, ВК сожмёт его и прозрачный фон пропадёт. Бот рецепт добавит, но предупредит об этом.

**Правка.** Меняется только то, что написано:

```
Изменить: Шарлотка
КБЖУ: 183/5,7/4,7/29
Ингредиент: сахар 80г
Шаг 2: Выпекайте 25 минут (понадобится сахар)
```

Ещё можно: `Название:`, `Описание:`, `Раздел:`, `Ингредиенты:` (заменить весь список), `Приготовление:` (заменить все шаги), `Добавить шаг:`, `Удалить шаг: 3`, `Убрать ингредиент: корица`. Новое фото - прикрепить файл к сообщению «Изменить».

**Остальное:** `Удалить: Шарлотка`, `Список` - все рецепты, `Помощь` - шаблон.

Удалённое не пропадает насовсем: всё хранится в истории GitHub, и рецепт можно вернуть.

## Подключение (один раз, минут 20)

Порядок важен: сначала Cloudflare, потом ВК.

### 1. Токен GitHub

1. github.com → аватарка → **Settings** → внизу **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Название: `vk-recipe-bot`. Срок: самый долгий (или No expiration).
3. **Repository access** → Only select repositories → `Fedik2005/1`.
4. **Permissions** → Repository permissions → **Contents: Read and write**.
5. **Generate token** и скопировать его (он покажется один раз), назовём его `GITHUB_TOKEN`.

### 2. Сообщество ВК

1. Создать сообщество (или взять своё) → **Управление**.
2. **Сообщения** → включить сообщения сообщества.
3. **Сообщения** → **Настройки для бота** → включить «Возможности ботов».
4. **Дополнительно** → **Работа с API** → **Ключи доступа** → **Создать ключ**, право **«Сообщения сообщества»**. Скопировать ключ, это `VK_TOKEN`.

### 3. Секрет на GitHub

Репозиторий `Fedik2005/1` → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**: имя `VK_TOKEN`, значение - ключ из шага 2.4. Через него бот отвечает в ВК.

### 4. Cloudflare

1. Зарегистрироваться на dash.cloudflare.com (бесплатно).
2. **Workers & Pages** → **Create** → **Create Worker** → имя `vk-recipe-bot` → **Deploy**.
3. **Edit code** → стереть всё → вставить содержимое `worker/worker.js` → **Deploy**.
4. Скопировать адрес воркера, вида `https://vk-recipe-bot.<имя>.workers.dev`.
5. Воркер → **Settings** → **Variables and Secrets** → добавить (тип **Secret**):
   - `GITHUB_TOKEN` - токен из шага 1;
   - `GITHUB_REPO` - `Fedik2005/1`;
   - `VK_TOKEN` - ключ из шага 2.4;
   - `VK_SECRET` - придумать любое слово латиницей, например `polkovniki2026`;
   - `VK_CONFIRMATION` и `VK_ALLOWED` - пока пропустить, они ниже.

### 5. Связать ВК с Cloudflare

1. ВК → **Управление** → **Работа с API** → **Callback API**. Версия API **5.199**.
2. Там написана «Строка, которую должен вернуть сервер». Добавить её в Cloudflare переменной `VK_CONFIRMATION`.
3. В ВК: **Адрес** - адрес воркера, **Секретный ключ** - тот же, что `VK_SECRET`. Нажать **Подтвердить**.
4. **Типы событий** → отметить **Входящие сообщения**.

### 6. Разрешить себе управлять ботом

1. Написать сообществу «Помощь». Бот ответит: «...Ваш id: 123456».
2. Добавить в Cloudflare переменную `VK_ALLOWED` = этот id (несколько id - через запятую).
3. Снова написать «Помощь»: придёт шаблон. Готово.

Чужим людям бот отвечает только, что это книга рецептов, и ничего не меняет.

## Обновить код воркера

В VS Code открыть терминал (Ctrl + `) и выполнить по очереди:

```
cd worker
npx.cmd --yes wrangler@4.154.0 login
npx.cmd --yes wrangler@4.154.0 deploy
```

После первой команды в браузере откроется Cloudflare - нажать **Allow**. Ключи в панели Cloudflare при этом не трогаются (`keep_vars = true` в `worker/wrangler.toml`).

Проверка: открыть адрес воркера с `?check` на конце.

## Если что-то не работает

- **Бот молчит совсем** - проверить Callback API в ВК (адрес, подтверждение, галочку «Входящие сообщения») и переменные в Cloudflare.
- **Пишет «Получила!», но дальше тишина** - на GitHub открыть вкладку **Actions** → «ВК-бот»: там видна ошибка. Чаще всего не задан секрет `VK_TOKEN` на GitHub.
- **«Не получилось передать сообщение на GitHub (код 401/404)»** - неверный `GITHUB_TOKEN` или `GITHUB_REPO` в Cloudflare.

## Для разработки

- Тесты разбора текста: `python -m unittest bot/test_recipe_text.py`
- Проверка сообщения без ВК и без публикации: `python bot/process.py --dry-run --text-file сообщение.txt --image фото.png`
- Пересобрать сайт после ручной правки `data/recipes.json`: `python bot/build.py`
- На GitHub: Actions → «ВК-бот» → **Run workflow** - можно отправить текст боту прямо оттуда, ответ будет в логе.
